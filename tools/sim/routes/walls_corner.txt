#   element 1: on the +y wall (wall 0), from x = 18 to 30, sticking out 4 in
#
# What each stop is for ("filter" = what check 8 should decide with the first values; "true cone" = whether the
# model's cone, 12 degrees by default, really meets the corner or element; walls_check.py prints both):
#   K4  back sensor 35.75 in from the -y wall, beam 12.25 in from the -x corner: filter rejects (corner); the true
#       cone is clean (it would meet the -x wall with cone_half_deg 19 or more)
#   K3  22 in from the wall: filter rejects; true cone clean
#   K1  14 in: filter rejects, by 0.3 in; true cone clean
#   K2  10 in: filter accepts, with 1 in to spare
#   E4  back sensor 14 in from the -x wall, 8 in beside element 0: filter accepts (1.45 in to spare)
#   E3  4 in beside it: filter rejects (keep-out); true cone clean
#   E2  2 in beside it: the true cone meets the element's corner and the reading is pulled short (about 1.9 in
#       with the blend, less than blockedMaxIn 2.5, so only check 8 stops it); filter rejects (keep-out). The case
#       W7 is about
#   E1  square in front of it: reads 4 in short; filter rejects (keep-out, and check 9)
#   E7, E6, E5  the same for element 1 (7 in beside, accepted with 0.45 in to spare; 2 in beside; in front)
#   K6  right sensor 20 in from the +x wall, beam 15 in from the +y corner: filter accepts (0.5 in to spare)
#   K5  the same, 13.25 in from the corner: filter rejects
#   K7  both sensors 9.75 in from their walls, beams 18.25 in from the bottom-left corner: filter accepts both
# With the model's default 12 degree cone the true cone cannot reach a corner from any stop where the filter's
# other checks pass (square within 10 degrees, within 36 in, the robot inside the field), so the K stops test the
# filter's margins against clean readings. Elements are where the true cone and the filter's footprint both matter.
#

# turns), so the outline stays inside the field with drifting odometry too.
